# Sizo Community Restoration Projects Website

## Project Overview

This project is a five-page website developed for Sizo Community Restoration Projects. The website provides information about the organisation, its services and ways for visitors to get involved.

## Pages

- Home
- About Us
- Services
- Get Involved
- Contact

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git
- GitHub

## Features

- Responsive navigation
- Community-focused content
- Services information
- Volunteer and sponsorship inquiry form
- JavaScript form validation
- Responsive layout for smaller screens
