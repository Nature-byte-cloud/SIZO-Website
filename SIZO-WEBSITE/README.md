SIZO Community Restoration Projects Website
Project Overview

SIZO Community Restoration Projects is a community-focused website designed to provide information about community development, restoration projects and ways for people to get involved.

The website was developed using HTML, CSS and JavaScript. The website contains five main pages and uses a consistent design and navigation structure throughout.

Part 2 Development

For Part 2, the website was improved by creating a responsive and consistent design across all pages.

Layout

CSS Flexbox and CSS Grid were used to create the website layout.

The navigation uses Flexbox to arrange the menu items, while CSS Grid is used for the content cards.

The card layout changes depending on the screen size:

Desktop: three columns
Tablet: two columns
Mobile: one column
Responsive Design

Responsive design was implemented using CSS media queries.

The website includes:

Desktop breakpoint
Tablet breakpoint
Mobile breakpoint
Relative units such as rem and percentages
Responsive images
Mobile navigation layout
Responsive card layouts
Responsive font sizes

The website was tested using Google Chrome Developer Tools at desktop, tablet and mobile screen sizes.

Responsive Image

The home page includes a responsive community image using the HTML picture element and srcset and sizes attributes.

This allows the image to adjust to different screen sizes.

JavaScript

JavaScript is used on the Get Involved page to validate the inquiry form.

The form checks that the required fields have been completed before displaying a confirmation message.

Testing

The website was tested using Google Chrome Developer Tools.

Desktop Testing

The website was tested using a desktop viewport.

The navigation, cards, images, text, buttons and page layout displayed correctly.

Tablet Testing

The website was tested using a tablet-sized viewport.

The card layout changed from three columns to two columns and the website remained readable and functional.

Mobile Testing

The website was tested using a mobile-sized viewport.

The navigation changed to a vertical layout and the content cards changed to a single-column layout.

The pages remained readable and there was no horizontal overflow.

GitHub

The project source code is maintained in a GitHub repository.

The repository contains the HTML pages, CSS stylesheet, JavaScript file, images and project documentation.
